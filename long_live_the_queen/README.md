# Long Live the Queen

Unofficial adapter for Long Live the Queen (Steam build, Ren'Py 8.5). See the notice for commercial-game adapters in the top-level README.

- `long_live_the_queen.rpy` (installed as `vnf_long_live_the_queen.rpy`): names the weekly schedule and image-only buttons, and exposes the skill and mood stats the generic scrape cannot see.
