# Mystic Cafe

Adapter for the sample game [Mystic Cafe](https://github.com/vnflight/mystic_cafe), played through on Ren'Py 8.5.2.

- `mystic_cafe.rpy` (installed as `vnf_progress.rpy`): progress tracking only, story beats and endings for the `progress` verb. The game's screens read fine without any button naming.
